# MERN Chat

Real-time private messaging app built with MongoDB, Express, React, Node.js and Socket.IO.

Use Node 24 for this project. In `server` and `client`, copy `.env.example` to
`.env`, fill in your own local values, and run `npm ci` followed by `npm run dev`.
Start the server before the client. Keep `.env` files untracked.

See [testing instructions](docs/TESTING.md) and the
[Atlas / Render / Vercel deployment guide](docs/DEPLOYMENT.md).
